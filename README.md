# Abhay Tyagi — Premium Developer Portfolio

A redesigned, responsive, dependency-free portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Notes
- Content is data-driven in `first.js`.
- Theme preference is persisted in localStorage.
- Project details use a modal instead of the original machine-specific local file paths.
- Contact form validates input and opens a real `mailto:` draft; it does not claim a server-side submission succeeded.
- No fake GitHub metrics, project statistics, social URLs, or backend responses were added.
